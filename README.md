# 3D-model-collection-assistant
统一收藏 MakerWorld、Printables、Thingiverse、Thangs、Cults3D 模型，支持封面、GIF动图、自定义分组、导出、多通道免Key翻译及中英文切换。<br>
Unified collection of MakerWorld, Printables, Thingiverse, Thangs, and Cults3D models, supporting cover images, GIFs, custom grouping, export, multi-channel keyless translation, and Chinese/English switching.<br>
